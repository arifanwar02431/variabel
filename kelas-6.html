01

Pengertian variabel

Definisi Variabel adalah nama yang menunjuk ke sebuah lokasi di memori komputer tempat suatu nilai disimpan. Nilai tersebut dapat dibaca dan diubah selama program berjalan.

Setiap variabel memiliki tiga komponen penting:

🏷️

Nama (identifier)

Label yang kita pakai untuk memanggil variabel. Contoh: umur.

📦

Nilai (value)

Data yang disimpan di dalamnya. Contoh: 12.

🧬

Tipe data (type)

Jenis nilainya: bilangan, teks, benar/salah, dll. Contoh: int.

Apa yang terjadi di memori?

Memori komputer (RAM) bisa dibayangkan sebagai deretan laci bernomor (alamat). Saat kamu menulis umur = 12, komputer menaruh nilai 12 di salah satu laci, lalu mencatat bahwa nama umur menunjuk ke laci itu. Kita tidak perlu menghafal nomor lacinya, cukup memakai namanya.

0x01·
umur0x0212
0x03·
nama0x04"Raka"
lulus0x05True
0x06·
0x07·
0x08·

Ilustrasi disederhanakan. Alamat memori sebenarnya jauh lebih panjang.

⚠️

Tanda = bukan “sama dengan”. Dalam pemrograman, = adalah operator penugasan (assignment): hitung nilai di sebelah kanan, lalu simpan ke variabel di sebelah kiri. Karena itu umur = umur + 1 masuk akal di kode, walaupun di matematika tidak mungkin. Untuk membandingkan, gunakan ==.

penugasan.py

umur = 12            # simpan 12 ke variabel umur
umur = umur + 1      # baca 12, tambah 1, simpan 13 ke umur
print(umur)          # tampilkan isi umur
print(umur == 13)    # == membandingkan, hasilnya True/False
13 True
02

Tujuan variabel

💾

Menyimpan data selama program berjalan

Input dari pengguna, hasil perhitungan, atau keadaan program (misalnya “game sudah selesai”) perlu disimpan agar bisa dipakai di langkah berikutnya.

🔀

Membuat program fleksibel

Program yang sama bisa bekerja untuk data yang berbeda. Kalkulator luas tidak perlu ditulis ulang untuk setiap ukuran persegi panjang.

📖

Membuat kode mudah dibaca

harga * jumlah jauh lebih jelas maknanya daripada 15000 * 3. Angka tanpa nama sering disebut magic number.

🧹

Menghindari pengulangan

Ubah nilai di satu tempat, maka seluruh bagian program yang memakainya ikut berubah. Lebih sedikit kesalahan.

Bandingkan sendiri

Tanpa variabel
tanpa_variabel.py

print(15000 * 3)
print(15000 * 3 * 0.1)
print(15000 * 3 - 15000 * 3 * 0.1)
# Harga naik? Ubah angka 15000 di 4 tempat!
Dengan variabel
dengan_variabel.py

harga = 15000
jumlah = 3
total = harga * jumlah
diskon = total * 0.1
print(total, diskon, total - diskon)
# Harga naik? Cukup ubah 1 baris.
03

Menulis variabel di kode

Ada tiga istilah yang perlu kamu kenal: deklarasi (membuat variabel), inisialisasi (memberi nilai pertama kali), dan penugasan ulang (mengganti nilainya).

Python

biodata.py

nama = "Raka"
kelas = 6
tinggi = 145.5
suka_coding = True

kelas = 7    # penugasan ulang

Cukup tulis nama = nilai. Python menentukan tipe datanya secara otomatis (dynamic typing).

JavaScript

biodata.js

let nama = "Raka";
let kelas = 6;
let tinggi = 145.5;
let sukaCoding = true;
const SEKOLAH = "SD Harapan";

kelas = 7;   // boleh, karena memakai let

Deklarasi memakai kata kunci let (nilai boleh diubah) atau const (nilai tetap).

04

Tipe data

Tipe data menentukan jenis nilai yang disimpan dan operasi apa yang bisa dilakukan padanya. Angka bisa dijumlahkan, teks bisa digabung.

Tipe (Python)NamaContohKeterangan
intBilangan bulatumur = 12Angka tanpa koma, bisa negatif.
floatBilangan desimalberat = 35.5Memakai titik, bukan koma.
strTeks (string)nama = "Ayu"Diapit tanda kutip "..." atau '...'.
boolLogika (boolean)hadir = TrueHanya dua nilai: True atau False.
listDaftarnilai = [80, 90, 75]Banyak nilai dalam satu variabel.

Memeriksa tipe dengan type()

cek_tipe.py

print(type(12))
print(type(12.0))
print(type("12"))
print(type(True))
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

Mengubah tipe (konversi)

konversi.py

umur_teks = input("Umurmu? ")  # input() selalu str
umur = int(umur_teks)          # ubah ke int
print(umur + 1)

harga = float("2.5")           # str -> float
pesan = "Nilai: " + str(90)    # int -> str
🧐

Angka di dalam tanda kutip adalah teks! 5 + 3 menghasilkan 8, tetapi "5" + "3" menghasilkan "53" karena kedua teks digabung (disebut konkatenasi). Sedangkan "5" + 3 menghasilkan error karena teks dan angka tidak bisa langsung dijumlahkan.

05

Aturan & konvensi penamaan

Ada aturan wajib (jika dilanggar, program error) dan konvensi (kebiasaan baik yang disepakati para programmer).

Aturan wajib

  • 1

    Diawali huruf atau garis bawah _, tidak boleh angka.

  • 2

    Hanya berisi huruf, angka, dan _. Tanpa spasi atau simbol seperti - . ! @ #.

  • 3

    Peka huruf besar-kecil (case-sensitive): Nilai dan nilai adalah dua variabel berbeda.

  • 4

    Bukan kata kunci (keyword) seperti if, for, class, True.

Konvensi (kebiasaan baik)

  • ✓

    Bermakna: jumlah_siswa, bukan js.

  • ✓

    Python → snake_case: nilai_akhir

  • ✓

    JavaScript → camelCase: nilaiAkhir

  • ✓

    Konstanta → HURUF_KAPITAL: NILAI_KKM

  • ✓

    Boolean seperti pertanyaan: sudah_lulus, is_aktif

06

Operasi pada variabel

Nilai variabel bisa dibaca, dihitung, lalu disimpan kembali. Python juga punya cara singkat untuk memperbarui nilai.

Memperbarui nilai

update.py

skor = 10        # 10
skor = skor + 5  # 15
skor += 5        # 20  (sama dengan skor = skor + 5)
skor -= 3        # 17
skor *= 2        # 34
skor /= 2        # 17.0 (hasil / selalu float)
SingkatSama dengan
x += 3x = x + 3
x -= 3x = x - 3
x *= 3x = x * 3
x /= 3x = x / 3

Banyak variabel sekaligus & menukar nilai

tukar.py

x, y = 3, 7      # x = 3 dan y = 7

# Cara umum: pakai variabel sementara
temp = x
x = y
y = temp

# Cara khas Python: satu baris
x, y = y, x

Menggabung teks

gabung.py

depan = "Rina"
belakang = "Putri"
lengkap = depan + " " + belakang
print(f"Halo, {lengkap}!")   # f-string
Halo, Rina Putri!

Contoh program utuh

Perhatikan bagaimana setiap variabel punya peran: menyimpan input, menyimpan hasil hitungan, lalu ditampilkan.

A. Luas & keliling persegi panjang (Python)

persegi_panjang.py

panjang = float(input("Panjang (cm): "))
lebar = float(input("Lebar (cm): "))

luas = panjang * lebar
keliling = 2 * (panjang + lebar)

print("Luas =", luas, "cm2")
print("Keliling =", keliling, "cm")

const HARGA_PENSIL = 3000;

08

Kegunaan: pola-pola variabel

Programmer sering memakai variabel dengan “peran” tertentu. Kenali enam pola yang paling umum:

🔢 Penghitung (counter)

Menghitung berapa kali sesuatu terjadi.


jawaban_benar = 0
jawaban_benar += 1

➕ Akumulator

Mengumpulkan (menjumlahkan) banyak nilai.


total = 0
total += harga_buku
total += harga_pensil

🚩 Penanda (flag)

Menyimpan keadaan ya/tidak.


game_selesai = False
if nyawa == 0:
    game_selesai = True

⌨️ Penyimpan input

Menyimpan jawaban dari pengguna.


nama = input("Siapa namamu? ")
print("Halo,", nama)

📥 Penampung sementara

Menyimpan nilai sebentar agar tidak hilang.


temp = a
a = b
b = temp

⚙️ Pengaturan

Nilai yang mengatur perilaku program.


KECEPATAN = 5
LEBAR_LAYAR = 800

Variabel vs konstanta

Konstanta adalah “variabel” yang nilainya tidak boleh diubah setelah dibuat, misalnya nilai π atau batas nilai KKM.

VariabelKonstanta
Nilai berubah?BolehTidak
Pythonskor = 0PI = 3.14 (kesepakatan)
JavaScriptlet skor = 0;const PI = 3.14;
Contohskor, waktu, saldoPI, NILAI_KKM, HARI_PER_MINGGU
konstanta.js

const PI = 3.14;
let jariJari = 7;
let luas = PI * jariJari * jariJari;

PI = 3;   // ❌ error!
TypeError: Assignment to constant variable.

Python tidak benar-benar mengunci konstanta. Huruf kapital hanya penanda bagi programmer: “jangan ubah nilai ini”.

10

Ruang lingkup (scope)

Scope menentukan di bagian mana sebuah variabel bisa dipakai. Ini mulai penting saat programmu memakai fungsi.

📢

Variabel global

Dibuat di luar fungsi. Bisa dibaca dari mana saja dalam program. Seperti papan pengumuman sekolah yang bisa dibaca semua kelas.

🧑‍🏫

Variabel lokal

Dibuat di dalam fungsi. Hanya “hidup” di dalam fungsi itu, lalu hilang saat fungsi selesai. Seperti tulisan di papan tulis kelas yang dihapus setelah pelajaran.

scope.py

NILAI_KKM = 75                      # global

def cek_lulus(nilai):
    status = nilai >= NILAI_KKM     # status adalah variabel lokal
    return status

print(cek_lulus(80))                # True
print(status)                       # ❌ status tidak dikenal di luar fungsi
True NameError: name 'status' is not defined
11

Kesalahan umum & cara memperbaikinya

Error itu normal, bahkan untuk programmer profesional. Yang penting tahu cara membacanya.

NameError

Memakai variabel sebelum dibuat


print(skor)   # ❌ skor belum ada
skor = 0

Perbaikan: buat (inisialisasi) variabel terlebih dahulu, baru dipakai.

NameError

Salah huruf besar/kecil


Nama = "Ayu"
print(nama)   # ❌ nama ≠ Nama

Perbaikan: tulis nama variabel persis sama setiap kali dipakai.

TypeError

Mencampur teks dan angka


umur = 12
print("Umur: " + umur)        # ❌
print("Umur: " + str(umur))   # ✓

Perbaikan: ubah tipe datanya dulu dengan str() atau int().

Bug logika

Nilai lama tertimpa


a, b = 5, 8
a = b    # a = 8, nilai 5 hilang!
b = a    # b = 8 juga ❌

Perbaikan: simpan dulu di variabel sementara (temp). Tidak ada pesan error, jadi lebih sulit ditemukan.

Penelusur kode

Programmer sering “menelusuri” kode baris demi baris untuk melihat isi setiap variabel. Tekan Berikutnya dan perhatikan tabel variabel berubah.

    Variabel di memori

    NamaNilaiTipe

    Output

    13

    Kuis variabel

    Delapan soal untuk menguji pemahamanmu. Beberapa soal meminta kamu menebak hasil kode.

    Skor kamu

    14

    Tantangan mandiri

    Kerjakan di komputer (misalnya di Thonny, IDLE, atau editor Python online). Coba sendiri dulu sebelum membuka contoh jawaban.

    1. Kartu biodata

    Buat variabel nama, umur, tinggi, dan hobi. Tampilkan kalimat perkenalan memakai semua variabel itu.

    Lihat contoh jawaban 
    
nama = "Dimas"
umur = 12
tinggi = 148.5
hobi = "bermain catur"
print(f"Halo, aku {nama}, umur {umur} tahun.")
print(f"Tinggiku {tinggi} cm dan aku suka {hobi}.")

    2. Uang saku seminggu

    Minta pengguna memasukkan uang saku harian. Hitung total uang saku selama 5 hari sekolah dan berapa yang tersisa jika ditabung 20%.

    Lihat contoh jawaban 
    
HARI_SEKOLAH = 5
uang_harian = int(input("Uang saku harian: "))
total = uang_harian * HARI_SEKOLAH
tabungan = total * 0.2
sisa = total - tabungan
print("Total:", total)
print("Ditabung:", tabungan)
print("Bisa dipakai:", sisa)

    3. Konversi suhu

    Ubah suhu Celsius ke Fahrenheit dengan rumus F = C × 9/5 + 32. Simpan setiap hasil di variabel yang namanya jelas.

    Lihat contoh jawaban 
    
celsius = float(input("Suhu (°C): "))
fahrenheit = celsius * 9 / 5 + 32
print(celsius, "°C =", fahrenheit, "°F")

    Rangkuman

    1. Pengertian: variabel adalah nama yang menunjuk ke lokasi di memori tempat nilai disimpan. Komponennya: nama, nilai, dan tipe data.
    2. Tujuan: menyimpan data selama program berjalan, membuat program fleksibel, mudah dibaca, dan tidak berulang.
    3. Penulisan: = adalah penugasan, bukan sama dengan. Python: nama = nilai; JavaScript: let / const.
    4. Tipe data utama: int, float, str, bool, list. Gunakan int(), float(), str() untuk konversi.
    5. Penamaan: diawali huruf/_, tanpa spasi & simbol, case-sensitive, bukan keyword. Gunakan nama bermakna.
    6. Kegunaan: penghitung, akumulator, penanda, penyimpan input, penampung sementara, dan pengaturan.
    7. Lanjutan: konstanta tidak diubah nilainya; variabel lokal hanya hidup di dalam fungsi, variabel global bisa dibaca di mana saja.
